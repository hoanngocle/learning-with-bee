## Level 1 pronunciation

The lesson and its vocabulary quiz play MP3 audio generated by Edge TTS using the `en-US-JennyNeural` voice. Set up Python before running the app on Windows.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

On macOS and Linux, use `python3` and `.venv/bin/python`. Set `TTS_PYTHON` to the interpreter path if you use another environment. The Node.js server needs that interpreter and outbound access to the speech service.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Tài khoản đăng nhập

Mở `/login` và dùng tài khoản mẫu `bee` với mật khẩu `Bee12345`.

Các tài khoản được khai báo trong `app/login/accounts.json`. Để tạo mục tài khoản mới, thay tên đăng nhập, tên hiển thị và mật khẩu trong đoạn Node.js sau, rồi thêm kết quả vào mảng JSON.

```js
const { randomBytes, scryptSync } = require("node:crypto");
const salt = randomBytes(16).toString("hex");
const passwordHash = scryptSync("mat-khau-moi", salt, 64).toString("hex");
console.log(JSON.stringify({ username: "ten-moi", displayName: "Tên hiển thị", salt, passwordHash }, null, 2));
```

Đặt `BEE_SESSION_SECRET` thành một giá trị ngẫu nhiên bí mật khi triển khai để phiên đăng nhập vẫn hợp lệ sau khi máy chủ khởi động lại. Nếu bỏ trống, máy chủ tạo khóa tạm cho lần chạy hiện tại.
